# SOC Analyst Journey 🔐

A collaborative cybersecurity learning journey focused on becoming SOC Analysts and building strong Blue Team fundamentals.

Our goal is to develop practical cybersecurity skills through structured learning, hands-on labs, security investigations and real-world projects.

## 🎯 Goal

Build practical skills in:

- Security Fundamentals
- Linux & Windows Security
- Network Security
- SIEM & Log Analysis
- Threat Detection
- Incident Response
- Threat Intelligence
- MITRE ATT&CK
- Blue Team Operations
- Python Security Scripting

## 📚 Learning Approach

Our learning process follows:

1. Understand the concepts.
2. Practise through hands-on exercises.
3. Document findings and investigation steps.
4. Build practical projects.
5. Review and improve continuously.

## 🎯 Long-Term Objective

Prepare for SOC Analyst Level 1 opportunities by developing strong technical fundamentals, practical investigation experience and a documented cybersecurity portfolio.
